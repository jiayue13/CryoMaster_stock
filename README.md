## 项目简介 | Project Overview

**CryoMaster Pro** 是一个智能冻存盒管理系统，为生物实验室提供高效、安全、便捷的样本管理解决方案。

CryoMaster Pro is an intelligent cryogenic storage management system that provides efficient, safe and convenient sample management solutions for biological laboratories.

---

## 📁 文件说明 | File Descriptions

### 1. **index.html**
主应用程序文件，提供完整的冻存盒管理界面。

**功能特性：**
- 🎨 现代化响应式设计，支持深色模式
- 📦 可视化9x9冻存盒网格布局
- 💾 支持批量导入样本数据
- 🔄 完整的撤销/重做功能
- ⚡ 快捷键支持（Ctrl+S保存、Ctrl+Z撤销等）
- 📊 实时样本信息展示
- 🔐 自动备份机制
- 🌍 多语言支持（中英文切换）

**技术栈：**
- HTML5
- CSS3（CSS变量、Grid布局）
- Vanilla JavaScript
- fflate压缩库

**使用方法：**
直接在浏览器中打开即可使用，无需服务器环境。

## 🚀 快速开始 | Quick Start

### 方式1：在线访问
访问: [https://www.jiayue.cn.ma](https://www.jiayue.cn.ma)

### 方式2：本地运行

1. **克隆仓库**
```bash
git clone https://github.com/jiayue13/CryoMaster_stock.git
cd CryoMaster_stock
```

2. **运行应用**
   - 直接打开 `index.html` 使用主应用
   - 打开 `cryomaster.html` 查看产品介绍
